Panduan Pengguna — Arsip Digital Sekolah

Panduan ini menjelaskan cara memakai aplikasi untuk setiap jenis pengguna (peran) di Arsip Digital Sekolah. Setiap panduan memuat langkah-langkah beserta tangkapan layar asli aplikasi.

Tangkapan layar dibuat otomatis dengan Playwright (apps/e2e/tests/docs) terhadap data demo, sehingga selalu mencerminkan tampilan aplikasi yang sebenarnya. Lihat Cara membuat ulang tangkapan layar.

Peran ditentukan saat pengguna diundang ke sekolah. Satu akun dapat memiliki peran berbeda di sekolah berbeda (multi-tenant).

Masuk ke aplikasi

Buka http://localhost:3000 (atau alamat produksi). Tanpa sesi, Anda akan diarahkan ke halaman masuk. Daftar akun baru, atau masuk dengan email & kata sandi.

  1. Isi Nama (khusus pendaftaran), Email, dan Kata sandi.
  2. Klik Daftar untuk membuat akun, atau Masuk bila sudah punya akun.
  3. Setelah masuk, Anda diarahkan ke Dasbor yang menampilkan daftar sekolah Anda.
  4. Klik salah satu kartu sekolah untuk membuka ruang kerja sekolah tersebut.

Peran Anda tampil di dasbor

Setiap kartu sekolah menampilkan peran Anda pada sekolah itu (mis. headmaster, operator). Menu di dalam sekolah menyesuaikan peran tersebut.

Peran tidak dapat dinaikkan sendiri. Hanya kepala sekolah yang dapat mengundang anggota. Antarmuka pengelolaan anggota masih berupa API (POST /schools/{id}/members lalu POST /members/accept); UI-nya menyusul.

Alur kerja umum (semua peran)

  1. Masuk dan pilih sekolah dari dasbor.
  2. Buka menu sesuai kebutuhan (lihat tabel di atas).
  3. Untuk pekerjaan yang mengubah data, hasilnya tercatat otomatis di jejak audit sekolah (dilihat oleh kepala sekolah/TU/auditor).
  4. Keluar dengan tombol Keluar di kanan atas.

Cara membuat ulang tangkapan layar

Tangkapan layar dihasilkan oleh generator Playwright yang berdiri sendiri (tidak ikut suite e2e default).

Prasyarat: PostgreSQL berjalan (migrasi + seed) dan dependensi terpasang.

# dari root repositori
npm run db:migrate
npm run db:seed
npm run install:browsers --workspace @arsip/e2e   # sekali saja

# hasilkan gambar ke docs/panduan-pengguna/gambar/
npm run docs:screenshots --workspace @arsip/e2e

Generator akan:

  1. menyiapkan sekolah demo SMA Negeri 1 Nusantara beserta 5 akun peran dan data contoh (tahun ajaran, kelas, siswa, nilai, dokumen, ijazah, keuangan, integrasi) lewat API — idempoten, aman dijalankan berulang;
  2. masuk sebagai tiap peran dan memotret halaman relevan;
  3. memverifikasi bahwa halaman tidak menampilkan galat dan bahwa panel role-specific muncul/hilang sesuai hak akses.

Versi HTML (gambar disematkan)

Setiap berkas Markdown di folder ini juga tersedia sebagai HTML mandiri: gambar disematkan sebagai data URI (base64), sehingga tiap berkas dapat dibuka atau dibagikan tanpa folder gambar/.

  • README.html, kepala-sekolah.html, kepala-tu.html, operator.html, guru.html, auditor.html

Bangkitkan ulang setelah panduan atau tangkapan layar diperbarui:

npm run docs:html
Dokumentasi ini dihasilkan dari berkas Markdown di docs/. Tangkapan layar disematkan sebagai gambar base64.
